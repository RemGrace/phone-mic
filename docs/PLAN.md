## Фаза 0. Проверки (spikes) — на своём телефоне и колонке

Главный вопрос: можно ли говорить в телефон и слышать себя из Bluetooth-колонки без раздражающей задержки.

- [ ] **S4. Каркас Expo + dev build.** `create-expo-app` (TypeScript), локальный Expo-модуль (Kotlin), dev build на телефон.
  Успех: из JS вызывается нативная функция модуля на телефоне.
  Итог:
- [ ] **S1. Нативный проход mic → A2DP.** `AudioRecord` → `AudioTrack` (low-latency) в модуле, звук в подключённую колонку.
  Успех: голос слышен из колонки; задержка измерена тестом хлопком (запись хлопка и звука из колонки на второй телефон, разница по осциллограмме).
  Итог:
- [ ] **S2. A2DP или SCO.** Тот же проход через профиль звонков (SCO). Если A2DP медленный — попробовать Oboe.
  Успех: таблица «режим → задержка → качество», выбран режим для MVP.
  Итог:
- [ ] **S3. Свист и эхо.** `AcousticEchoCanceler`, `NoiseSuppressor`, разные расстояния до колонки.
  Успех: понятно, на каком расстоянии и с какими настройками свиста нет.
  Итог:
- [ ] **S5. Выключенный экран.** Foreground service с уведомлением.
  Успех: звук идёт 10 минут с выключенным экраном, без обрывов.
  Итог:

**Шлюз Фазы 0:** на твоей колонке есть режим, в котором комфортно говорить. Если нет — решаем, что делать с идеей, до дизайна.
