# phone-mic — инструкции для Claude Code

Я — Арсений. Мы делаем Android-приложение на React Native / Expo: телефон работает как микрофон, звук идёт в Bluetooth-колонку. Общайся по-русски, кратко: сначала вывод или следующее действие. Код, коммиты, README и тексты для стора — на английском.

`phone-mic` — рабочее имя. Название, лого и бренд — задача Фазы 1.

## С чего начинать

1. `docs/PLAN.md` — фазы, проверки (spikes), трекинг. Начинай с первого невыполненного пункта.
2. `docs/HANDOFF.md` — идея, факты с источниками, риски, решения.

Порядок, который задал Арсений: **план → проект → дизайн → функционал**. Не перескакивай: без пройденного шлюза Фазы 0 (задержка) не пиши UI, без одобренных макетов (Фаза 2) не верстай экраны.

## Порядок работы

1. Explore / read-only audit.
2. План.
3. Минимальные изменения.
4. Проверка: тесты и сборка. Звук и поведение на устройстве проверяет Арсений.
5. Короткий отчёт: что изменено, как проверено, какие риски остались.

Отделяй проверенное от предположений. Не утверждай, что слышал звук или проверял телефон: это делает Арсений.
