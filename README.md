# phone-mic

Turn your phone into a microphone: speak or sing into the phone and hear yourself from a Bluetooth speaker. Like a portable PA system built from things you already have.

**Status:** planning. The first step is measuring the latency of a native mic → Bluetooth path on real devices.

- Platform: Android first (React Native + Expo, native audio module), iOS later.
- Roadmap: see [docs/PLAN.md](docs/PLAN.md).
